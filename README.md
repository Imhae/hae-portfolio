# HAE Portfolio

Portfolio của HAE, UI/UX Designer đang học Business Analysis.

- `index.html`: bản chính, cuộn ngang có quán tính (tự chuyển sang cuộn dọc trên màn hình hẹp).
- `versions/v1-cuon-doc.html`: bản đầu tiên, cuộn dọc.

Trang là một file HTML tĩnh, không cần build. Mở trực tiếp `index.html` trong trình duyệt để xem.

## Cần thay trước khi gửi nhà tuyển dụng

- Số liệu, dự án, kinh nghiệm (đang là nội dung mẫu).
- Email, link LinkedIn.
- Link CV: sửa biến `CV_URL` trong thẻ `<script>` cuối `index.html`.
- Ảnh chân dung và ảnh cover dự án.
